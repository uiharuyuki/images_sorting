# 画像振り分けツール

指定したフォルダ（入れ子フォルダ含む）の画像を一覧表示し、「保存」「削除」を
素早く振り分けるためのツールです。

「削除」は完全削除ではなく、フォルダ内の `_trash/`（元のサブフォルダ構造を保持）への
**移動**です。誤って削除しても <kbd>Z</kbd> で取り消せます。最後にまとめて完全削除もできます。

---

## ブラウザ版（推奨・インストール不要）

GitHub Pages 上でそのまま動く **ブラウザ完結版** です。サーバも Python も不要。

**公開URL: https://nirayuki-slides.github.io/images_sorting/**

### 特長
- **完全ローカル処理**：[File System Access API](https://developer.mozilla.org/docs/Web/API/File_System_Access_API)
  を使い、選択したフォルダをブラウザ内で直接読み書きします。
  画像やパスは **外部に一切送信されません**（アップロードもサーバ保存もなし）。
- インストール・ビルド不要。ページを開いて「フォルダを選択」するだけ。

### 使い方
1. 上記URLを **Google Chrome** または **Microsoft Edge**（デスクトップ版）で開く
2. 「フォルダを選択」をクリックし、対象フォルダを選んで **読み書きを許可**
3. 一覧から <kbd>S</kbd>（保存）/ <kbd>D</kbd>（削除）で振り分け

### 対応ブラウザ（重要）
File System Access API に対応した **Chromium 系のデスクトップブラウザ限定** です
（Chrome / Edge など）。Firefox / Safari、およびスマホ等の未対応環境では
画面に案内が表示され、利用できません。

## 操作方法（共通）

| 操作 | 内容 |
|------|------|
| サムネイルをクリック | 拡大表示（モーダル） |
| <kbd>D</kbd> | 削除（`_trash/` へ移動） |
| <kbd>S</kbd> | 保存（振り分け済みマーク） |
| <kbd>←</kbd> <kbd>→</kbd> <kbd>↑</kbd> <kbd>↓</kbd> | フォーカス移動（モーダル中は前後の画像へ） |
| <kbd>Z</kbd> | 直前の削除を取り消し |
| <kbd>Enter</kbd> | フォーカス中の画像を拡大 |
| <kbd>Esc</kbd> | モーダルを閉じる |

- 左サイドバーでフォルダを切り替えられます。
  - **すべて（再帰）**: ルート配下の全画像をまとめて表示
  - 各フォルダ: そのフォルダ直下の画像のみ表示
- 「ゴミ箱を空にする」で `_trash/` 内を完全削除（取り消し不可）。
- サムネイルは遅延読み込み（IntersectionObserver）のため、大量画像でも固まりにくい構成です。

## 仕様メモ

- 対応拡張子: jpg / jpeg / png / gif / webp / bmp
- 削除時は `_trash/` 内に元のサブフォルダ構造を保って移動するため、復元も元の場所に戻ります。
- ファイル移動は `FileSystemFileHandle.move()` を使用し、非対応時は「読み取り→書き込み→元を削除」で
  エミュレートします（完全削除は「ゴミ箱を空にする」を押したときのみ）。

## Python 版（ローカルサーバ・任意）

ローカルでサーバを立てて使う従来版も残しています。`app.py` は Python 標準ライブラリのみで
動作し、`127.0.0.1:8765` で待ち受けます（外部には公開されません）。

### Windows
1. `start.bat` をダブルクリック
2. 既定のブラウザで `http://127.0.0.1:8765/` が自動で開きます
3. 上部の入力欄に対象フォルダのパスを入れて「読み込み」

### Mac / Linux
```bash
python3 app.py
```
ブラウザで `http://127.0.0.1:8765/` を開きます。

> ブラウザ版とは異なり、Python 版は手動でフォルダパスを入力します。
> ポートを変えたい場合は `app.py` 冒頭の `PORT` を変更してください。
