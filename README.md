# 画像振り分けツール

指定したフォルダ（入れ子フォルダ含む）の画像を一覧表示し、「保存」「削除」を
素早く振り分けるためのローカルWebアプリです。**追加インストール不要**で、
Python 3 さえあれば動きます（標準ライブラリのみ使用）。

「削除」は完全削除ではなく、フォルダ内の `_trash/` への**移動**です。
誤って削除しても取り消せます。最後にまとめて完全削除もできます。

## 使い方

### Windows
1. `start.bat` をダブルクリック
2. 既定のブラウザで `http://127.0.0.1:8765/` が自動で開きます
3. 上部の入力欄に対象フォルダのパスを入れて「読み込み」

> Python が入っていない場合は `start.bat` が案内を表示します。
> [python.org](https://www.python.org/downloads/) からインストールするか、
> `start.bat` 内のコメントを外すと `winget` で自動インストールできます。

### Mac / Linux
```bash
python3 app.py
```
ブラウザで `http://127.0.0.1:8765/` を開きます。

## 操作方法

| 操作 | 内容 |
|------|------|
| サムネイルをクリック | 拡大表示（モーダル） |
| `D` | 削除（`_trash/` へ移動） |
| `S` | 保存（振り分け済みマーク） |
| `←` `→` `↑` `↓` | フォーカス移動（モーダル中は前後の画像へ） |
| `Z` | 直前の削除を取り消し |
| `Enter` | フォーカス中の画像を拡大 |
| `Esc` | モーダルを閉じる |

- 左サイドバーでフォルダを切り替えられます。
  - **すべて（再帰）**: ルート配下の全画像をまとめて表示
  - 各フォルダ: そのフォルダ直下の画像のみ表示
- 「ゴミ箱を空にする」で `_trash/` 内を完全削除します（取り消し不可）。

## 仕様メモ

- 対応拡張子: jpg / jpeg / png / gif / webp / bmp
- サーバは `127.0.0.1`（localhost）のみで待ち受け、外部には公開されません。
- 削除時は `_trash/` 内に元のサブフォルダ構造を保って移動するため、復元も元の場所に戻ります。
- ポートを変えたい場合は `app.py` 冒頭の `PORT` を変更してください。
